## 一、2026-08-27 做了什么（按时间）

1. **P7 端点巡逻**（`decision._patrol`）：朝目标端点走，x 进端点 ±30 内翻转；未标端点退回按时间掉头。菜单「巡逻端点」现场标定。
2. **不追怪**：`far_offset 1280→140`、`approach false`。理由（用户真机日志）：追怪时 33% 时间在 APPROACH、目标在多只怪间跳换、ATTACK 时距离中位 96 px 超普攻范围。
3. **`facing: key`**：朝向直接取决策按住的方向键，只检测前进方向（用户反馈"背后有怪不转身"——现在背后的怪根本不进检测，掉头时自然扫到）。
4. **中间层重搜**（`roi.py`）：小窗丢后先在上一位置 ±300/±120 内找、≥0.72 接受。录像扫参：0.70/0.71 会锁到上层平台别人的名牌，0.72 起干净。修用户反馈"跳跃后名牌跟踪消失"——实为屏幕边缘名牌只有 0.67–0.76 分够不到全局阈值 0.82。
5. **搜索窗裁到 search_band**：局部/中间层窗口曾漂进 HUD，锁死在聊天栏文字上（y=646，score 0.70）35 s。
6. **边缘半模板**：角色贴屏幕最左/右时名牌被切一半，整张模板永远匹配不上（真机曾 LOST 150 s 一动不动）。左边缘用模板右半、右边缘用左半，≥0.72。连续 400 帧 100%。
7. **P9 卡住检测 / P10 跳跃恢复**（见上表）。`bg_dx` 用相位相关（y350–650 带，0.25 缩放，≈1 ms；本机位响应 0.97–0.99 无失败帧）。
8. **根因：Pico v1 固件 UDP 收不了连发包**。实测连发 2 个 PING 回 1 个、5 个回 0 个、间隔 20 ms 发 5 个回 0 个、间隔 50 ms 才全收；KEY_PRESS 期间 sleep 也不收包。
   bot 换向发 `KEY_UP×2 + KEY_DOWN` → KEY_DOWN 必丢 → 角色停住；攻击/拾取/心跳/同步互相撞包 → 随机丢键。
   **这解释了此前几乎所有真机怪象**（卡住、走走停停、背对怪、追怪抖动）。
   修复（A 端 `pico_client.py`）：所有控制命令进队列，后台线程 ≥60 ms 单发；KEY_PRESS 后再等其按住时长；心跳只在无其他流量时发；
   RELEASE_ALL 清空队列插队；相邻重复 KEY_UP 去重；KEY_PRESS 积压 ≥3 丢弃。固件 v2（`pico/p1_wifi_hid/code.py`）已写、未烧（Pico 在 B 电脑上）。
9. **工具**：`app.py --seconds N`（定时停）、`--set a.b.c=v`（临时覆盖配置）、`--record`（启动即录，后台线程写）；菜单加 `key` 朝向、跳跃开关。
10. **地图坐标估计（`worldpos.py`，用户要求）**：屏幕 x 只在镜头顶住时等于地图位置；累加每帧背景滚动 bg_dx 得镜头位移，`world_x = 屏幕x + cam_x`，端点可标在镜头跟随区。
    防漂移三招（都在录像/合成数据上验证）：① |bg_dx|<1 死区不累加（静止噪声逐帧累加 10 min 漂 89 px→加死区后可忽略）；
    ② 「人在走+背景不滚+人贴屏幕边缘(<0.2 或 >0.8 屏宽)」才判定到地图边界并归零/学 cam_w（这游戏镜头是死区式的，中段人走镜头不动，不能当边界）；
    ③ 地标校准：标端点时 `pick_landmark` 在头顶上方几个候选框里挑「自相似度最低」的一块（泥墙/草地花纹每 ~150 px 重复，只看纹理会错配到相邻瓦片），
    运行时每 5 帧在预测位置附近找它、要求匹配≥0.9 且峰唯一、修正量超「漂移预算」要连续 20 次一致才认。
    离线：手动走全图录像 world_x 单调无跳变、地标校准修正量中位 2 px；实机 70 s：world_x 每帧有值、相邻跳变>40px 共 0 次、+0 ms。
    **地图模式的实机端点标定尚未验证**（自动开车标定时角色掉进坑里，两端点记成同一处；需用户用菜单手动标，或角色不在坑里时标）。

## 二、这张地图 / 这套硬件的事实（不要重新发现）
1. **Pico v1 固件**：见 §一.8。任何新命令都必须走 `PicoClient.send(wait_reply=False)` 队列，别绕过。
2. **地图**（woniu-mogu，南港旁）：约 1.76 屏宽（镜头行程 ≈975 px）。角色屏幕 x <450 或 >800 时镜头被顶住（屏幕 x 可当地图坐标），
   500–800 时镜头在跟随。底层地面是巡逻层（y≈550–572）；地图**左端有个坑**（左右皆墙、右墙约 250 px 高跳不出），坑左上是带邮箱/NPC 的平台；
   右侧有"南港"路牌（传送门），角色在路牌前偶发 5 s 不走。两端点 484/963 都在镜头顶住区，标定有效。
3. **摄像头**：Insta360 Ace Pro 2，`camera.source: Insta360`，只暴露 Brightness。录像同步写会把 30 fps 拖到 17，已改后台线程。
4. **Pico** IP 192.168.1.69（也可广播发现）。
5. **名牌模板** `templates/players/wudicc.png` 47×14 紧抠；阈值 全局 0.82 / 局部 0.65 / 中间层 0.72 / 边缘 0.72 绑定这张模板。
6. **踩过的坑**：`timeout -s INT` 和不带锚的 `pkill -f "app.py ..."` 都会杀掉工具 shell 自己（用 `--seconds` 或 `pkill -f "^python3 app.py"`）；
   实机标定覆盖 `homography.json` 会让旧录像全错位（每段录像配自己的标定副本，`--calib` 指定）；被打闪白帧不能做模板。
