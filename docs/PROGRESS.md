   RELEASE_ALL 清空队列插队；相邻重复 KEY_UP 去重；KEY_PRESS 积压 ≥3 丢弃。固件 v2（`pico/p1_wifi_hid/code.py`）已写、未烧（Pico 在 B 电脑上）。

   **换角色/换地图后名牌识别不到的根因与修法（会反复遇到）**：模板必须是**只有名牌那一条的紧抠**，且从**当前矫正画面（1280×720）**里按当前缩放抠——
   不能用整只角色贴图（身体每帧在动，实测只匹配 0.53 → 必 LOST），也不能用别的缩放/背景下截的图（实测 0.78，够不到全局 0.82）。
   步骤：抓一帧矫正画面 → 定位角色脚下的名牌条 → 按 `y1:y2, x1:x2` 抠（宽≈54、高≈15）→ 存成 `templates/players/<名>.png` →
   `settings.yaml` 设 `anchor_dx≈宽/2`（水平中心）、`anchor_dy≈高-2`（名牌底≈脚底）→ **开车走 3~4 秒验证**（`ROIProvider.locate_player` 中位应 ~0.99、丢失 0%）。
   名牌半透明，背后地图滚动时个别帧会掉到 0.6，靠局部跟踪(0.65)+中间层+5帧去抖兜住，无需降全局阈值。验证脚本见 `scratchpad/val_pipeline.py`。
6. **踩过的坑**：`timeout -s INT` 和不带锚的 `pkill -f "app.py ..."` 都会杀掉工具 shell 自己（用 `--seconds` 或 `pkill -f "^python3 app.py"`）；
   实机标定覆盖 `homography.json` 会让旧录像全错位（每段录像配自己的标定副本，`--calib` 指定）；被打闪白帧不能做模板。
